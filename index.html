Step 1 — Go to console.firebase.google.com → Create a project (disable Google Analytics if prompted)

Step 2 — In your project: Project Settings → General → Your apps → Add app → Web (</>). Copy the firebaseConfig object and paste it into this file replacing the placeholder values.

Step 3 — In Firebase console: Authentication → Get started → Email/Password → Enable → Save

Step 4 — In Firebase console: Firestore Database → Create database → Start in test mode → Choose a region → Enable

Step 5 — Save the file and open it in your browser. That's it — register your account and start logging trades! ✅
